# WooCommerce Order Confetti Lite

Lightweight confetti animation for WooCommerce order success pages.

WooCommerce Order Confetti Lite adds a smooth and performance-optimized confetti effect to the WooCommerce "Order Received" page after a successful purchase. The animation is rendered using HTML5 Canvas, automatically starts after page load, and cleans itself up once completed.

## Features

- Lightweight canvas-based confetti animation
- Displayed only on WooCommerce order success pages
- Optimized for desktop and mobile devices
- Adaptive particle rendering for better performance
- Automatic animation cleanup after completion
- Support for reduced-motion accessibility preferences
- No configuration required
- No external libraries or dependencies

## Requirements

- WordPress
- WooCommerce
- PHP 7.4+

# WooCommerce Order Confetti Lite

افکت سبک بارش کاغذ رنگی برای صفحه موفقیت سفارش ووکامرس.

این افزونه پس از ثبت موفق سفارش در ووکامرس، یک افکت بارش کاغذ رنگی روان و بهینه را در صفحه «سفارش دریافت شد» نمایش می‌دهد. انیمیشن با استفاده از Canvas اجرا شده، پس از بارگذاری صفحه آغاز می‌شود و پس از پایان اجرا به‌صورت خودکار از صفحه حذف خواهد شد تا کمترین تأثیر را بر عملکرد سایت داشته باشد.

## امکانات

- افکت بارش کاغذ رنگی مبتنی بر Canvas
- اجرا فقط در صفحه موفقیت سفارش ووکامرس
- بهینه‌سازی شده برای موبایل و دسکتاپ
- کنترل تعداد ذرات برای حفظ عملکرد مرورگر
- حذف خودکار عناصر پس از پایان انیمیشن
- پشتیبانی از تنظیمات کاهش حرکت (Accessibility)
- بدون نیاز به تنظیمات یا پیکربندی
- بدون وابستگی به کتابخانه‌های جانبی

## پیش‌نیازها

- وردپرس
- ووکامرس
- PHP 7.4 یا بالاتر
